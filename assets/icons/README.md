# Technology icons

These SVG files are stored locally so the profile does not depend on third-party badge rendering at runtime.

- `python.svg` and `aws.svg`: Skill Icons, https://github.com/tandpfun/skill-icons (MIT; original SVG artwork retained).
- `n8n.svg`: Simple Icons, https://github.com/simple-icons/simple-icons (MIT). The mark is shown in n8n's recognizable pink on the same dark tile used by the other icons.
- `openai.svg`: OpenAI mark, sourced from the OpenAI logo artwork. OpenAI trademarks remain the property of OpenAI; use is only to identify the technology used in projects and does not imply endorsement.

The surrounding dark tiles use the same #242938 background and rounded-square treatment as the existing Skill Icons row.
